# Forever Dungeon Quests

Know before you queue. **Forever Dungeon Quests** shows you every quest tied
to a dungeon in **WoW: Forever** — which ones you already have, which ones
you're missing (and exactly where to pick them up), and which ones you've
already completed. Check a dungeon's quest list *before* you travel or queue,
instead of finding out you skipped something after you're already inside.

## Features

- **One clean window.** A dungeon list on the left (filterable by level
  range), a quest table on the right. Click a dungeon, the table updates —
  no separate screens to navigate.
- **Status at a glance.** Every quest is tagged **Missing** (red), **In Log**
  (green), or **Done** (gray), with missing quests sorted to the top.
- **Pickup info included.** Quest giver, zone, and `/way` coordinates for
  every quest, so you know exactly where to go.
- **Faction-aware.** Only shows quests for your faction (plus neutral ones) —
  no clutter from quests you'll never be able to take.
- **Key/attunement notes.** Dungeons that need a special key or item (e.g.
  the Shadowforge Key for Blackrock Depths) call that out up front.
- **Minimap button.** One click opens the window from anywhere — no need to
  be near or inside a dungeon.
- **Looks native.** Automatically themes to match [EllesmereUI](https://www.curseforge.com/wow/addons/ellesmereui)
  if you have it installed; falls back to a clean flat panel if you don't.

## How to use it

Click the minimap button (a yellow "!" icon) or type `/fdq` to open the
window. Type `/fdq <name>` to jump straight to a dungeon, e.g. `/fdq
deadmines` or `/fdq scarlet` (partial names work).

| Command | What it does |
|---|---|
| `/fdq` | Opens the window, keeping your last-selected dungeon. |
| `/fdq <name>` | Opens the window with that dungeon pre-selected. |
| `/fdq scan` | Forces a rescan of your completed quests. |

## Beta notice

WoW: Forever is currently in Beta, and so is this addon. Quest data was
hand-transcribed from a community guide and may be incomplete or shift
before launch — a handful of quests (mostly in Ruins of Lordaeron) are still
marked TBD by the source. Found something wrong? Open an issue on
[GitHub](https://github.com/ImSundee/forever-dungeon-quest/issues).
